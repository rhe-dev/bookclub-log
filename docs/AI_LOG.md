# AI 도구 사용 기록 (AI_LOG)

> README §6 "AI 도구 사용 내역"과 서술형 문항 4(실패·문제 경험)의 재료.
> **실패·삽질은 발생 즉시 기록한다**

## 기록 형식

```
### [날짜] 도구 — 작업
- 시도: 무엇을 시켰나
- 결과: 잘됨 / 수정 필요 / 실패
- 배운 것: (실패라면) 왜 틀렸고 어떻게 잡았나
```

### [2026-07-25] Claude Code — 과제 분석·기획

- 시도: 과제 안내문 분석, 평가 포인트 추출, 주제 후보 비교, 기획 문서 세트 초안 작성
