# QA 체크리스트

> 목적 두 가지: (1) Lv3 루브릭(안내문 4항목) 검증, (2) **기능 추가 시 회귀 보장 스위트** — 흐름 단위로 나눠, 새 기능이 들어올 때 해당 흐름 섹션을 다시 돌린다.
> `[회귀]` 표시는 과거에 실제로 깨졌거나 로직이 얽혀 있어, 변경 시 반드시 재확인해야 하는 항목.
> 자동화 범위: 주문 전이 맵은 유닛 테스트 25개로 상시 보장 — 나머지는 수동 시나리오.

## A. 세션·진입 흐름 (랜딩 → 로그인 → 클럽 컨텍스트)

- [ ] 비로그인 첫 진입(`/`): 서비스 소개(기능 3종) + '모임 시작하기' CTA가 보이는가
- [ ] 로그인 모달: 계정 목록에 가입 클럽·역할(모임장)이 표시되는가 / 로딩 스켈레톤·최소 높이로 모달 높이가 튀지 않는가
- [ ] 계정 선택 → 첫 가입 클럽 책방으로 이동, 환영 토스트
- [ ] 로그인 상태의 랜딩: CTA가 '내 책방으로 가기'로 바뀌는가
- [ ] 보호 경로(책방·책 상세·문집·마이) 비로그인 직접 진입 → "로그인 후 이용" 토스트 + 랜딩
- [ ] `[회귀]` 로그인 상태에서 새 탭·새로고침으로 보호 경로 직접 진입 → 오탐 리다이렉트 없이 통과 (하이드레이션 — AI_LOG 2026-07-28)
- [ ] `[회귀]` 무효 세션(DB 리시드로 멤버 소실·스토리지 오염): 첫 API 요청에서 자동 로그아웃 + "다시 로그인해 주세요" 토스트
- [ ] GNB 클럽 전환: 내 클럽 목록(클럽별 역할 태그·현재 클럽 체크) → 선택 시 그 클럽 책방, 모임장 표기가 클럽 기준으로 갱신되는가
- [ ] 로그아웃: GNB 드롭다운·마이페이지 양쪽에서 동작, 랜딩 복귀 + 안내 토스트

## B. 책방·토론 흐름 (서비스 코어)

- [ ] 책방: 지금 읽는 책 히어로 + 책장 그리드 + 상태 필터가 시드만으로 즉시 탐색되는가
- [ ] 책장 '더보기': 12권 초과 시 더보기 버튼으로 이어 붙는가 / 필터 결과가 0이어도 상단 CTA(문집·책 추가)는 유지되는가 (D-026)
- [ ] `[회귀]` 클럽 전환 후 책방·문집 만들기의 책 목록이 **현재 클럽 것만** 보이는가
- [ ] 책 추가·수정·삭제는 모임장만 — UI 노출 + 서버 403 (타 클럽 모임장도 거부)
- [ ] 빈 책방: 역할별 온보딩 문구 + 다음 행동 버튼
- [ ] 토론: 코멘트(페이지·인용 앵커)/답글 1단계/공감 토글/작성자만 수정·삭제
- [ ] `[회귀]` 답글 달린 코멘트 삭제 → '삭제된 코멘트'로 자리 유지, 답글 보존 (소프트 딜리트)
- [ ] 코멘트 수정 시 '수정됨' 표기, updatedAt 갱신

## C. 문집 주문 흐름 — 서비스(주문자) 측면

- [ ] 만들기 3단계: 완독 책만 선택 가능(비활성 카드 안내 + **서버 검증**) / 선택 순서 = 수록 순서(서버 보존) / 코멘트 없는 책 경고 / 어느 클럽의 문집인지 표기
- [ ] 기본값: 제목(클럽명 문집)·부수(멤버 수), 부수 1~100 클램프 + 검증 메시지
- [ ] 마이페이지 주문 목록: 클럽 무관 "내가 주문자"인 건 전체 + 카드에 클럽명·주문번호 표시, 10건 초과 시 '더보기'
- [ ] 내 코멘트 모아보기: 책·클럽 표시, 클릭 시 해당 토론 이동, '더보기' 페이지네이션, 삭제된 코멘트·삭제된 책 제외
- [ ] 상태는 사용자 언어 칩 + 4그룹(접수·제작·배송·완료) 스텝, 진행 이력은 명사형 라벨 + 일시
- [ ] 상태별 주문자 액션 노출: 접수·확인=취소 / 배송완료=구매 확정·환불 요청·재제작 요청 / 그 외·종결=버튼 없음
- [ ] `[회귀]` 환불·재제작 사유: 사유 미선택 시 확인 비활성 + 서버 400 / 기타는 상세 5~500자(카운터·서버 검증 동일) / 사유 전환 시 상세 입력 초기화 / 접수 후 진행 이력에 사유 표시
- [ ] 권한: 주문자 아닌 멤버의 취소·확정·요청 → 서버 403 (UI에는 애초에 미노출)

## D. 문집 주문 흐름 — 어드민 측면

- [ ] `[회귀]` 전이 맵: 순방향 8단계 정상 / 역행·건너뛰기 거부 / 허용 분기만(취소·환불·재제작) — **유닛 테스트 25개 통과가 기준**
- [ ] 관리자 단계 진행 → 마이페이지 스텝·이력(날짜)에 반영
- [ ] 환불 처리: REFUND_REQUESTED → REFUNDED(관리자만, 사유 불요) / 재제작 승인: REMAKE_REQUESTED → IN_PRODUCTION 재진입
- [ ] 관리자가 주문자 전용 전이(구매 확정 등) 시도 → 서버 거부
- [ ] CSV 다운로드: 내용이 화면과 일치, 엑셀 한글 호환(BOM), 클럽·사유 등 최신 필드 반영
- [ ] (admin 화면 구현 시) 주문 테이블에 주문자·클럽·주문일·상태·사유가 보이고 단계 진행이 되는가

## E. 비정상 경로·반응형 (루브릭 ③·④)

- [ ] 목록 로딩: 스켈레톤 / 비어 있음: 빈 상태 + 다음 행동 / API 실패: 에러 뷰 + 재시도
- [ ] 입력 실수: 필드별 검증 메시지(무엇이 왜), 입력 시 에러 해소
- [ ] 모바일 375px: 책방·토론·문집·마이페이지가 자연스러운가, 코멘트 폼 한 손 조작
- [ ] 극단 축소: 가로 스크롤 발생 시 GNB·푸터가 함께 늘어나는가 / iOS 위아래 바운스 없음
- [ ] 데스크톱: 문집 만들기·admin 테이블이 제 폭을 쓰는가

## Lv3 루브릭 매핑

3. **비정상 경로** → E + A(무효 세션), C(사유 검증)
