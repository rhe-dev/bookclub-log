# QA 체크리스트

> 목적 두 가지: (1) Lv3 루브릭(안내문 4항목) 검증, (2) **기능 추가 시 회귀 보장 스위트** — 흐름 단위로 나눠, 새 기능이 들어올 때 해당 흐름 섹션을 다시 돌린다.
> `[회귀]` 표시는 과거에 실제로 깨졌거나 로직이 얽혀 있어, 변경 시 반드시 재확인해야 하는 항목.
> 자동화 범위: 주문 전이 맵은 유닛 테스트로 상시 보장 + 도커 기동 후 API 시나리오(§F)로 서버 규칙 일괄 확인 — 나머지는 수동 시나리오.

## A. 세션·진입 흐름 (랜딩 → 로그인 → 모임 컨텍스트)

- [ ] 비로그인 첫 진입(`/`): 서비스 소개(기능 3종) + '모임 시작하기' CTA가 보이는가
- [ ] `[회귀]` 로그인 모달이 열리는가 — 지연 로딩(D-041) 이후 첫 클릭에서도 지체 없이 뜨는가
- [ ] 로그인 모달: 계정 목록에 가입 모임·역할(모임장)이 표시되는가 / 로딩 스켈레톤·최소 높이로 모달 높이가 튀지 않는가
- [ ] 계정 선택 → 첫 가입 모임 책방으로 이동, 환영 토스트
- [ ] 로그인 상태의 랜딩: CTA가 '내 책방으로 가기'로 바뀌는가
- [ ] 보호 경로(책방·책 상세·문집·마이) 비로그인 직접 진입 → "로그인 후 이용" 토스트 + 랜딩
- [ ] `[회귀]` 로그인 상태에서 새 탭·새로고침으로 보호 경로 직접 진입 → 오탐 리다이렉트 없이 통과 (하이드레이션 — AI_LOG 2026-07-28)
- [ ] `[회귀]` 무효 세션(DB 리시드로 멤버 소실·스토리지 오염): 첫 API 요청에서 자동 로그아웃 + "다시 로그인해 주세요" 토스트
- [ ] `[회귀]` GNB 멤버 메뉴가 열리는가 — 지연 로딩(D-041) 이후 모임 목록이 처음부터 채워져 높이가 튀지 않는가
- [ ] GNB 모임 전환: 내 모임 목록(모임별 역할 태그·현재 모임 체크) → 선택 시 그 모임 책방, 모임장 표기가 모임 기준으로 갱신되는가
- [ ] `[회귀]` 로그아웃 → 재로그인: 스토어·localStorage·쿼리 캐시가 모두 비워져 **이전 세션의 운영자 필터가 남지 않는가** (D-032)
- [ ] 로그아웃: GNB 드롭다운·마이페이지 양쪽에서 동작, 랜딩 복귀 + 안내 토스트

## B. 책방·토론 흐름 (서비스 코어)

- [ ] 책방: 지금 읽는 책 히어로 + 책장 그리드 + 상태 필터가 시드만으로 즉시 탐색되는가
- [ ] 책장 '더보기': 12권 초과 시 더보기 버튼으로 이어 붙는가 / 필터 결과가 0이어도 상단 CTA(문집·책 추가)는 유지되는가 (D-026)
- [ ] `[회귀]` 지금 읽는 책이 2권 이상일 때 캐러셀: 드래그·스와이프·화살표·도트로 순환하고 **연타해도 빈 화면이 나오지 않는가** / 필터를 바꿔도 히어로는 유지되는가
- [ ] `[회귀]` 책 제목이 2줄 이상이어도 그리드 행이 어긋나지 않고 카드가 위쪽 정렬되는가
- [ ] 필터 전환 시 책장 영역만 스켈레톤(히어로는 유지), 한 영역 실패가 다른 영역을 죽이지 않는가
- [ ] `[회귀]` 모임 전환 후 책방·문집 만들기의 책 목록이 **현재 모임 것만** 보이는가
- [ ] 책 추가·수정·삭제는 모임장만 — UI 노출 + 서버 403 (타 모임 모임장도 거부)
- [ ] 빈 책방: 역할별 온보딩 문구 + 다음 행동 버튼
- [ ] 토론: 코멘트(페이지·인용 앵커)/답글 1단계/공감 토글/작성자만 수정·삭제
- [ ] 읽을 예정인 책에도 코멘트가 열려 있고, **상태별 입력창 문구**로 기대를 맞추는가 (D-039)
- [ ] 코멘트끼리 구분선·인용구 배경이 화면에서 충분히 구분되는가
- [ ] `[회귀]` 답글 달린 코멘트 삭제 → '삭제된 코멘트'로 자리 유지, 답글 보존 (소프트 딜리트)
- [ ] 코멘트 수정 시 '수정됨' 표기, updatedAt 갱신

## C. 문집 주문 흐름 — 서비스(주문자) 측면

### 만들기 4단계 (D-033~035)

- [ ] 진입 가드: 완독한 책이 하나도 없으면 GNB '문집 만들기'가 토스트로 이유를 알리고 빈 마법사로 보내지 않는가
- [ ] 1단계(책 선택): 완독 책만 선택 가능(비활성 카드 안내 + **서버 검증**) / 전체 선택·해제 / 선택 순서 = 수록 순서(서버 보존) / 담은 책 패널이 그리드 폭을 침범하지 않는가
- [ ] `[회귀]` 1단계에서 분량이 최소 쪽수에 못 미치면 **다음으로 넘어가기 전에** 배너로 막는가 / 선택을 바꾸면 그 배너가 사라지는가
- [ ] 2단계(수록 확인): 예상 분량·수록 순서가 보이고, 코멘트 없는 책을 뺄 수 있는가
- [ ] 3단계(판형·표지): 판형 3종 중 분량이 안 맞는 판형은 이유와 함께 비활성인가 / 표지 미리보기에 모임 이름·기간이 반영되는가
- [ ] `[회귀]` **견적 요청은 3단계 진입 시 1회만** 나가는가 — 책을 고를 때마다·부수를 칠 때마다 호출되지 않는가
- [ ] 4단계(부수·확인): 부수 1~100 클램프 + 검증 메시지 / 부수 변경 시 금액이 클라이언트에서 즉시 계산되는가 / 예상 수령일이 '쯤'으로 안내되는가
- [ ] 기본값: 제목(모임명 문집)·부수(멤버 수)
- [ ] `[회귀]` 참여 회원 미선택 시 라벨까지 에러 색으로 바뀌는가
- [ ] `[회귀]` 다음/이전 이동 시 스크롤 — 앞으로 갈 때는 맨 위, 뒤로 갈 때는 이전 위치 복원
- [ ] `[회귀]` 다른 모임의 완독 책은 애초에 목록에 없고, 섞어 보내면 서버가 `ORDER_BOOK_INVALID`로 거절하는가 (D-040)

### 주문 후 (마이페이지)

- [ ] 주문 목록: 모임 무관 "내가 주문자"인 건 전체 + 카드에 모임명·주문번호·판형·금액·수령 예정·송장이 표시되는가, 10건 초과 시 '더보기'
- [ ] 내 코멘트 모아보기: 책·모임·앵커(페이지 칩·인용) 표시, 클릭 시 해당 토론 이동, 삭제된 코멘트·삭제된 책 제외 (수정·삭제는 상세에서만)
- [ ] `[회귀]` 탭·페이지네이션: 탭 상태가 URL(?tab=)로 유지되고, 목록이 줄어 현재 페이지가 사라지면 마지막 페이지로 되돌아가는가(빈 화면 갇힘 없음)
- [ ] 상태는 사용자 언어 칩 + 4그룹(접수·제작·배송·완료) 스텝, 진행 이력은 명사형 라벨 + 일시
- [ ] 상태마다 **다음에 무엇을 기다리거나 해야 하는지** 한 줄이 붙는가 — 진행 중엔 예상 수령일, 배송 완료엔 구매 확정 안내, 환불·재제작 요청 후엔 처리 안내
- [ ] 상태별 주문자 액션 노출: 접수·확인=취소 / 배송완료=구매 확정·환불 요청·재제작 요청 / 그 외·종결=버튼 없음
- [ ] `[회귀]` 환불·재제작 사유: 사유 미선택 시 확인 비활성 + 서버 400 / 모든 사유에 상세 입력 가능, 기타만 필수(5~500자, 카운터·서버 검증 동일) / 사유 전환 시 상세 초기화 / 접수 후 진행 이력에 사유 표시
- [ ] 권한: 주문자 아닌 멤버의 취소·확정·요청 → 서버 403 (UI에는 애초에 미노출)

## D. 문집 주문 흐름 — 어드민 측면

### 주문 관리

- [ ] `[회귀]` 전이 맵: 순방향 7단계 정상 / 역행·건너뛰기 거부 / 허용 분기만(취소·환불·재제작) — **유닛 테스트 통과 + §F 시나리오가 기준**
- [ ] 관리자 단계 진행 → 마이페이지 스텝·이력(날짜)에 반영
- [ ] 환불 처리: REFUND_REQUESTED → REFUNDED(관리자만, 사유 불요) / 재제작 승인: REMAKE_REQUESTED → IN_PRODUCTION 재진입
- [ ] 관리자가 주문자 전용 전이(구매 확정 등) 시도 → 서버 거부
- [ ] 주문 테이블: 주문일시·최근 변경·주문번호·상태·모임·주문자·제목·부수·판형·금액, 행 전체 클릭으로 상세 진입
- [ ] `[회귀]` 좁은 화면에서 **카드로 바뀌지 않고 테이블 + 가로 스크롤**이며, 스크롤이 끝까지 가는가 (D-031)
- [ ] 필터: 주문일 기간·정렬·표시건수·통합 검색 인풋·상태·처리 대기만·초기화 — 인풋이 플레이스홀더가 다 보일 최소 너비를 유지하는가
- [ ] `[회귀]` 필터가 **URL 쿼리에 실려** 링크 공유·뒤로 가기로 복원되는가 / 다른 메뉴에 갔다 돌아와도 마지막 조건이 살아나는가 (D-038)
- [ ] 일괄 처리: 체크박스 선택 → 공통 다음 단계만 제안, 실패 건은 건너뛰고 결과 보고
- [ ] CSV 3종(선택·현재 페이지·필터 전체): 내용이 화면과 일치, 엑셀 한글 호환(BOM), 모임·사유·운영자 메모 반영, 파일명에 범위가 드러나는가
- [ ] 운영자 메모: 단계 진행 시 근거를 남기고 이력·CSV에 표시되는가
- [ ] GNB 처리 대기 배지가 실제 대기 건수와 맞는가

### 북프린트 연동 (D-033~036)

- [ ] 주문 상세 연동 패널: 판형·주문 시 분량 vs 현재 분량·적격 여부가 보이는가
- [ ] `[회귀]` **주문 확인(CONFIRMED) 전에는 발주 버튼이 뜨지 않고**, 서버도 거부하는가
- [ ] `[회귀]` 취소된 주문에는 "발주할 수 있어요" 안내가 뜨지 않는가
- [ ] 발주 → 벤더 주문번호 발급 + 상태 IN_PRODUCTION, 이벤트 로그에 `order.created`
- [ ] `[회귀]` 중복 발주 시도 → `PRINT_ALREADY_ORDERED`
- [ ] 제작처 이벤트 수신 5종: `production.confirmed`·`production.started`는 **주문 상태를 바꾸지 않고** 벤더 상태만 갱신 / `production.completed`→제작완료 / `shipping.departed`→배송시작 + 송장 발급 / `shipping.delivered`→배송완료
- [ ] 미발주 주문에 이벤트 → `PRINT_NOT_ORDERED` / 알 수 없는 이벤트 → `PRINT_WEBHOOK_EVENT_INVALID`
- [ ] 이력의 행위자가 VENDOR로 구분되는가
- [ ] 응답 분리: `vendorOrderUid`·`vendorStatus`는 어드민에만, `trackingNumber`는 주문자에게도

### 회원·모임 관리 (D-030 개정, D-037)

- [ ] 회원 목록: 이름·ID·모임명 통합 검색, 모임 ID·가입기간 필터, 페이지네이션
- [ ] 모임 목록: 모임명·ID·개설기간 필터, 멤버 수·책 수·주문 수
- [ ] 상세는 모달이 아니라 **페이지**이며, 주문↔회원↔모임을 오가도 뒤로 가기가 자연스러운가
- [ ] 상세 상단 이동이 '뒤로'(히스토리)와 '○○ 관리'(목록)로 나뉘고 라벨과 실제 이동이 일치하는가
- [ ] 운영자 메모: 회원·모임 상세에서 저장되고 목록에 메모 있음 표시가 뜨는가
- [ ] `[회귀]` 회원·모임은 **조회 + 메모만** — 정지 등 상태 변경 기능이 없는 것이 맞는가

### 운영자 세션

- [ ] 운영자 진입: 로그인 모달 '관리자' 탭 → 운영자 GNB로 전환되고 서비스 메뉴는 사라지는가
- [ ] `[회귀]` 배타 세션: 회원 세션으로 /admin 접근 차단, 운영자 세션으로 /bookshelf 접근 차단 (D-029)

## E. 비정상 경로·반응형 (루브릭 ③·④)

- [ ] 목록 로딩: 스켈레톤 / 비어 있음: 빈 상태 + 다음 행동 / API 실패: 에러 뷰 + 재시도
- [ ] 빈 상태 문구가 **'조건에 맞는 것이 없음'과 '아직 하나도 없음'을 구분**하는가 (필터가 있는 목록)
- [ ] `[회귀]` 없는 경로(`/nope`) → 한국어 공통 404 + GNB·푸터 유지 + 돌아갈 버튼 (D-042)
- [ ] `[회귀]` 없는 대상(`/books/틀린id`, 운영자 주문·회원·모임 상세) → **무엇을 못 찾았는지** 밝히고 '다시 시도' 대신 목록으로 돌아갈 길을 주는가 (D-042)
- [ ] 입력 실수: 필드별 검증 메시지(무엇이 왜)
- [ ] `[회귀]` **입력을 고치는 순간 그 필드의 에러가 사라지는가** — 책 추가(제목·저자·참여 회원·기간), 코멘트(내용·페이지), 문집(제목·부수), 환불 사유 (D-043)

## Lv3 루브릭 매핑

1. **첫 진입 이해** → A(랜딩·로그인), B(빈 책방 온보딩)
2. **주문 상태를 사용자 말로** → C(상태 칩·스텝·이력), D(북프린트 벤더 상태를 사용자 언어로 번역)
3. **비정상 경로** → E + A(무효 세션), C(사유 검증), D·F(전이·발주 거부)
4. **반응형** → E
